# プロジェクト概要

文書を作成するWebアプリです。

ブラウザ上でリッチテキスト形式で文書を作成します。
作成した文書はデータベースではなくマークダウン形式のファイルとして保存します。

文書を表示する際にマークダウンからHTMLに変換してレスポンスします。

アプリはDockerイメージとしてリリースされ、ユーザーはコンテナをローカルで起動して利用します。

# 技術選定

Next.jsのポートフォリオにするため、React/Next.jsを利用します。

リッチテキストを実装するライブラリはMilkdownを利用します。

# 機能詳細

## ファイルとURLの対応

環境変数 `ORENO_ROOT` で文書ファイルの **ルートディレクトリ** を指定します。

URLのホスト名からの相対パスと、ファイルパスのルートディレクトリからの相対パスが相互に対応します。

例えば、

* Orenoをポート番号 `3000` で稼動させている。
* ルートディレクトリは `/oreno` である。

という場合、

`http://localhost:3000/docs/hello`

にアクセスすると

`/oreno/docs/hello.md`

を読み取って文書を表示します。

ただし、このルールだと

`http://localhost:3000/`

にアクセスした場合のファイルパスを決められません。このURLへのリクエストはエラーにせず、`http://localhost:3000/index` にリダイレクトします。

URLに `*` などのファイルパスの指定で特別な意味のある記号が含まれている場合は404エラーになります。

## 表示モードと編集モード

リクエストされた文書は、ユーザー設定に保存されたモードで表示します。設定がない場合は読み取り専用の表示モードで表示します。

画面にある「編集モードに切り替え」ボタンを押すと編集可能になります。編集モードでは「表示モードに切り替え」ボタンで表示モードに戻せます。
選んだモードは保存され、ページを移動したりリロードしても変わりません。

編集モードでは「削除」ボタンも表示され、これを押すとファイルを削除します。

## 編集内容の自動保存

編集モードでの編集内容は、最後の編集から0.5秒たつと自動的にファイルへ保存されます。「保存」ボタンはありません。
日本語入力の変換中(未確定)の文字は保存されません。

保存が終わるまでの間、ヘッダーのパスの右に「（保存中...）」と表示します。
保存に失敗したときは、画面上部に「文書の保存に失敗しました。」を数秒間表示し、パスの右の表示を「（保存失敗）」に変えます。自動ではやり直さず、次に編集したときにもう一度保存を試みます。

アプリ内で別のページへ移動するときは、保存待ちの編集もその場で保存します。ただし、ブラウザのタブを閉じたときは保存できないことがあります。

## ページの新規作成

存在しないファイルを参照するURLにアクセスすると、モードの設定に関わらず編集モードで空の文書を開きます。このとき保存されたモードの設定は変わりません。

新規作成では自動保存をしません。パスの右に「（新規）」と「保存」「キャンセル」ボタンを表示します。
「保存」ボタンを押すとURLに対応するマークダウンファイルを作成し、保存後は設定されたモードで表示します。
「キャンセル」ボタンを押すと、直前まで表示していたページに戻ります。保存せずに移動すると、入力した内容は失われます。

## ファビコン

文書ルートフォルダに `favicon.ico` を置くと、そのファイルがファビコンとして使われます。
置かれていない場合は、ノートとペンのデフォルトのアイコン(`public/default-favicon.ico`)を表示します。

## 認証

ローカルでサーバーを起動するためログインは不要です。

## バージョン管理

文書はGitでバージョン管理します。

ただし、保存(自動保存を含む)・削除による操作ではファイルの変更・削除のみを行い、自動的にコミットはしません。
コミットはユーザー自身が任意のタイミングでGitクライアントを使って行います。

# 制約

## 表現できる要素

文書はマークダウンとして保存するので、マークダウンで表現できない要素は文書に追加できません。

## キャッシュによる誤表示

ブラウザの戻る/進むボタンでページを再表示したとき、最新の状態が反映されていない場合があります。
ブラウザが直前に表示したページの内容を再利用するためです(リンクのクリックやURLの入力、リロードでは最新の内容を取得します)。
次のような場合に起きます。

- 別のタブや別のブラウザで、同じページの文書の保存・削除やスターの切り替えをした
- アプリの外(エディタやGitの操作など)で、文書のファイルを編集した

最新の状態を表示したいときは、リロードしてください。
