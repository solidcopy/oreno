# 表示内容に影響する変更とキャッシュ

ブラウザは、戻る/進むボタンで再表示するページに、直前に取得した描画結果(ルーターキャッシュ)を再利用します。
このため、ページの表示内容に影響する変更をServer Actionで行うときは、変更後に `revalidatePath` を呼んでキャッシュを破棄してください。
呼び忘れると、戻る/進むで古い内容が表示されます。

- 文書の保存・削除、スターの切り替えなど、そのページ自身の表示が変わる場合は、そのページのパスを指定する
- ページ共通の表示(ヘッダーのプロジェクト名など)が変わる場合は、影響する範囲に合わせてパスを指定する
- 表示に使わないデータの記録(現時点の閲覧履歴など)では不要。表示に使うようになったときに見直す
