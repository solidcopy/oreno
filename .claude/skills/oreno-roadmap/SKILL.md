# 予定している機能

以下は基本的な機能を実装したあとに予定している機能であり、**現時点では実装しない**。これらに該当する依頼を受けた場合や、関連する提案をしようとした場合は、現時点では実装対象外であることをユーザーに報告すること。

## 全文検索

入力したキーワードが含まれる、または関連する文書を検索する。

## 孤立ページのチェック

`/index` 以外で、他のどのページからもリンクされていないページを探す。リンク切れチェック画面(`/.oreno/link_broken_check`)とは別の画面として実装する予定で、画面のデザインは別途用意してある。

リンク切れチェック画面には、孤立ページのカードを表示しない。
