# 配布形態

アプリはDockerイメージとしてリリースし、ユーザーはコンテナをローカルで起動して利用する。

# 認証

ローカルでサーバーを起動する前提のため、ログイン機能は不要。認証を実装しないこと自体がこのプロジェクトの現在の仕様であり、既存コードの不備ではない。

(将来Webに公開してリモートアクセスを受け付ける場合は認証が必要になるが、これは oreno-roadmap スキルにある予定機能であり、現時点では実装しない。)

# バージョン管理

文書はGitでバージョン管理する。

ただし、保存・削除ボタンによる操作では**ファイルの変更・削除のみ**を行い、自動的にコミットはしない。コミットはユーザー自身が任意のタイミングでGitクライアントを使って行う。

保存・削除機能を実装・修正する際、`git commit` やそれに類する処理を自動的に呼び出さないこと。
