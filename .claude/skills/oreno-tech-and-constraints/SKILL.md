# 技術選定

このプロジェクトはNext.jsのポートフォリオを兼ねているため、React/Next.jsを採用している。この目的があるため、React/Next.js以外のフレームワークへの置き換えは提案しないこと。

リッチテキストエディタにはMilkdownを利用する。別のエディタライブラリへの置き換えを相談された場合は、この採用理由(および置き換えの動機が何か)を確認すること。

# 制約

文書はデータベースではなくMarkdown形式のファイルとして保存し、表示時にMarkdownからHTMLに変換してレスポンスする。

このため、**Markdownで表現できない要素は文書に追加できない**。Markdownの範囲を超える機能(例: 独自のインタラクティブな埋め込み要素)を依頼された場合は、この制約に抵触することを報告すること。
