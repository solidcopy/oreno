# 表示モードと編集モード

リクエストされた文書は、デフォルトでは読み取り専用（表示モード）で表示する。

画面の「編集」ボタンを押すと編集可能になり、同時に「保存」ボタンが表示される。「保存」ボタンを押すと編集内容をファイルに保存する。

編集モードでは「削除」ボタンも表示され、これを押すとファイルを削除する。

# ページの新規作成

存在しないファイルを参照するURLにアクセスすると、編集モードで空の文書を開く(404にはしない。404になるのはURL自体がファイルパスに対応できない場合のみで、これはoreno-file-routingスキルの管轄)。

文書を入力して保存ボタンを押すと、URLに対応するMarkdownファイルを新規作成する。
