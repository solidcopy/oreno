# 参照先の案内

このファイルには、文書編集UIの基本(モード、自動保存、新規作成)を書く。個別の編集機能は、作業内容に応じて次のファイルを読む。

- 下線・上付き・下付き、数式の無効化、表のセル内改行 → `references/text-decorations.md`
- リンクの設定・解除、ヘッダーのページ移動の入力欄(候補のドロップダウンの仕様を含む) → `references/link.md`
- 画像の挿入・変更 → `references/image.md`(候補のドロップダウンは `references/link.md` と共通の仕組みなので、あわせて読む)

# 表示モードと編集モード

リクエストされた文書は、ユーザー設定のモード(`mode`。仕様は oreno-user-settings スキルを参照)で表示する。未設定のときは読み取り専用の表示モードで開く。

- 表示モードでは「編集モードに切り替え」ボタンとその右に「削除」ボタンを表示する。「編集モードに切り替え」を押すと編集可能になる
- 編集モードでは「新規作成」ボタン(「表示モードに切り替え」の左。動作は表示モードと同じ)、「表示モードに切り替え」ボタン、「削除」ボタンを表示する。新規作成中(ファイルが存在しないとき)は「新規作成」を表示しない。「表示モードに切り替え」を押すと、保存待ちの編集があれば先に保存してから表示モードにする。保存に失敗したときは、編集が失われないよう編集モードのままにする
- 2つのモード切り替えボタンは、同じ幅で表示する
- 「移動」ボタンを、モード切り替えボタンと「削除」の間に表示する(新規作成中は表示しない)。表示中のページの.mdファイルを移動またはリネームする。押すと「新規作成」と同じ形のポップアップで移動先のパスを入力する。ラベルは「移動するページのパス」、実行ボタンは「移動」。パスの扱い(`.md` の付与、フォルダの自動作成、空欄・`.` から始まる名前を含むパス・既存ファイルのエラーメッセージ)は新規作成と同じ。移動できたら移動先のページへ遷移する。編集モードでは移動の直前に保存待ちの編集を保存し、保存に失敗したら移動しない。移動したら、閲覧履歴とスター付きページに記録されている移動元のパスも移動先に付け替える(`renamePageInSettings`。移動先がすでに記録されていれば重複させない。付け替えに失敗しても移動は成功扱い)
- 「削除」を押すとファイルを削除する(確認ダイアログを出す)。削除したあとは、下記の新規作成の画面と同じ状態になる
- モードを切り替えるたびに、ユーザー設定の `mode` へ保存する(ページを移動したりリロードしても変わらないようにするため)

# 編集内容の自動保存

編集モードでは、編集内容を自動的にファイルへ保存する。「保存」ボタンはない(新規作成を除く。次節を参照)。

- 最後の編集から0.5秒、追加の編集がなかったときに保存する(1文字ごとに保存しないため)
- 日本語入力などの変換中(未確定)は保存しない。確定したあとに保存する
- ヘッダーの現在ページのパスの右に、保存の状態を表示する(`Header.tsx` の `saveStatus`)
  - 保存待ちまたは保存中: （保存中...）をやや目立たない色で表示する
  - 保存に失敗した: （保存失敗）を赤で表示する。メッセージが消えたあとも保存できていないことが分かるようにするため
  - 保存に成功した: （保存済み）を（保存中...）と同じ色で表示する。次の編集で（保存中...）に変わるまで、そのまま表示し続ける
  - ページを開いてからまだ編集していない間は何も出さない
  - モードを切り替えると、保存の状態表示は消える(表示モードに切り替えたあとも、再び編集モードにした直後も何も出さない)
- 保存に失敗したときは、画面上部に「文書の保存に失敗しました。」を赤い背景で表示し、ユーザー設定画面の保存通知と同じ3秒で消す
- 失敗しても自動では再試行しない。次に編集したときに改めて保存を試みる
- アプリ内で別のページへ移動するときは、保存待ちの編集を待たずに、移動の直前の内容を今すぐ保存する。ブラウザのタブを閉じる場合は対象外(保存できないことがある)
- 保存の途中でさらに編集されたときは、その編集の保存が改めて走る。保存済みの内容と同じになったとき(編集して元に戻したときなど)は保存しない
- 保存に使う Server Action のボディサイズ上限は、`next.config.ts` の `serverActions.bodySizeLimit` で10MBにしている(デフォルトの1MBでは大きな文書が保存できないため)

# ページの新規作成

存在しないファイルを参照するURLにアクセスすると、ユーザー設定の `mode` に関わらず編集モードで空の文書を開く(404にはしない。404になるのはURL自体がファイルパスに対応できない場合のみで、これはoreno-file-routingスキルの管轄)。このときユーザー設定の `mode` は更新しない。

新規作成では、自動保存はしない。

- ヘッダーのパスの右に、（保存中...）の代わりに（新規）を表示し、その右に「保存」「キャンセル」ボタンを表示する(`saveStatus` が `"new"`)
- 「保存」を押すと、URLに対応するMarkdownファイルを新規作成する。保存したあとのモードは、ユーザー設定の `mode` に従う。保存に失敗したときは、新規作成の画面のまま、自動保存の失敗と同じメッセージを表示する
- 「キャンセル」を押すと、直前まで表示していたページに戻る(ブラウザの戻る)。履歴がなく戻れないときは `/index` へ移動する
- 保存の途中は、「保存」「キャンセル」を押せないようにする
- 入力した内容は、保存せずにページを移動すると失われる
