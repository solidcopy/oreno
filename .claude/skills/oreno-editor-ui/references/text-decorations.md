# 下線の文字修飾

編集モードでは、文字に下線を引ける。Markdownファイルの中ではHTMLの `<u>…</u>` として保存する。

- テキストを選択すると出るツールバーの、取り消し線の右にある「U」ボタンで下線を引く(もう一度押すと外す)
- ショートカットは Mod+U
- `__テキスト__` と入力すると下線になる(Milkdown標準では太字になるが、下線を優先している)。`**テキスト**` は従来どおり太字
- 実装は `src/components/underlinePlugin.ts`。読み込み時に対になる `<u>` と `</u>` を1つのマークにまとめ、対応する `</u>` がない `<u>` はHTMLのまま残す
- 表示モードでは `rehype-raw` で `<u>` を要素として解釈する。`<u>` 以外の生HTMLは従来どおり `rehype-sanitize` が取り除く(`src/lib/markdown.ts`)

# 上付き・下付きの文字修飾

編集モードでは、文字を上付き・下付きにできる。Markdownファイルの中ではHTMLの `<sup>…</sup>`(上付き)と `<sub>…</sub>`(下付き)として保存する。

- テキストを選択すると出るツールバーの、下線の右にある「上付き」「下付き」ボタンで設定する(もう一度押すと外す)
- ショートカットと、Markdown入力からの自動変換は用意していない
- 上付きと下付きは同時に付けられない。片方を付けると、もう片方は外れる
- 上付き・下付きの直後に続けて入力した文字には、マークが付かない(修飾なしの文字になる)。太字や下線は、直後に入力した文字にも同じ修飾が付く
- 実装は `src/components/scriptPlugin.ts`。下線(`underlinePlugin.ts`)と同じ仕組みで、対になる開きタグと閉じタグを1つのマークにまとめる
- 表示モードでは、`<sup>` `<sub>` は `rehype-sanitize` の既定で許可されているため、追加の設定なしで表示される

# 数式(LaTeX)の無効化

Milkdown(Crepe)が標準で持つ数式(LaTeX)の機能は無効にしている。

- `$テキスト$` と入力しても数式にならない
- テキストを選択すると出るツールバーに、数式のボタンは表示しない
- 実装は `src/components/MarkdownEditor.tsx` で、Crepeの `features` に `[CrepeFeature.Latex]: false` を指定している

# 表のセル内改行

編集モードでは、表のセルの中で改行できる。Markdownファイルの中ではHTMLの `<br>` として保存する(GFMの表はセル内に改行を書けないため)。

- セル内ではShift+Enterで改行する(Enterは表から抜ける操作のまま)
- 表のセル結合には対応していない(GFMの表の範囲で扱う)
- 実装は `src/components/tableBreakPlugin.ts`。読み込み時にセル内の `<br>` `<br/>` `<br />` を改行ノードへ変換し、書き出し時にセル内の改行を `<br>` にする。セルの外の改行は標準の処理のまま
- Milkdown標準の `remark-preserve-empty-line` が `<br>` をすべて取り除くため、読み込みの変換はremarkプラグインの並びの先頭に差し込んでいる(後ろだと `<br>` が消え、保存し直したときにファイルからも失われる)
- Milkdown標準では表の中に改行を入れられないため、`MarkdownEditor.tsx` で `hardbreakFilterNodes` からtableを外している(コードブロックは従来どおり不可)
- Milkdown標準のShift+Enterは、改行の直後にもう一度押すと改行を段落に置き換える。セルは段落を持てないため、表が分割されたりカーソルが表の外へ出たりする。そこでセルの中では、標準より優先するショートカットを `tableBreakPlugin.ts` に用意し、押した回数だけ改行を入れる(セルの外は標準のまま)
- 表示モードでは `rehype-raw` で `<br>` を要素として解釈し、`rehype-sanitize` の既定で許可されているため、追加の設定なしで改行される
