# 画像の挿入

編集モードでは、画像挿入モーダルで画像を挿入する。Markdownファイルの中では `![代替テキスト](画像パス "タイトル")` として保存する。

- 行頭の＋アイコンで開くメニュー(スラッシュメニュー)の先頭にある「Image」を選ぶと、モーダルが開く。開く前に、メニューを開くために入力した `/` などは消す
- エディタにフォーカスがあるときは、Mod+Pでもモーダルを開く(ブラウザの印刷より優先する)。メニューから開くときと違い、文字は消さずにカーソル位置へ挿入する
- 画像を選択している(画像をクリックして選択状態にしている)ときにMod+Pを押すと、各入力欄が選択中の画像の画像パス・タイトル・代替テキストで初期入力される。このときモーダルのタイトルと実行ボタンは「画像を変更」になり、押すと新しい画像を挿入せずに、選択中の画像を置き換える。初期入力された画像パスの候補のドロップダウンは、画像パスを入力し直すまで表示しない。それ以外のときは、入力欄が空欄の「画像を挿入」になる
- モーダルには「画像パス」「タイトル」「代替テキスト」の入力欄がある。タイトルと代替テキストは空欄でもよい。入力値は常に空欄から始まる
- 「画像を挿入」を押す(Enterキーも同じ)と、カーソル位置に画像を挿入する。段落の途中にも挿入でき、その場合は文の中の画像になる。画像だけの行にしたければ、画像だけの段落にする
- 画像パスが空欄(空白のみを含む)のときは「画像を挿入」を押せない。Enterでも挿入されない
- 「キャンセル」、モーダルの外側のクリック、Escキーでモーダルを閉じる。閉じたあとはエディタにフォーカスが戻る
- 画像パスは入力された文字列をそのまま書き込む(`images/my_image.png` ならそのまま)。文書セットの外の画像は扱わない
- 画像パスの入力中は、リンク設定モーダルのリンク先と同じ仕組み(候補の絞り込み・並び順・キー操作・存在判定・ファイル一覧の取得。仕様は `link.md` を参照)で、ドロップダウンに候補を表示する。違いは、候補が画像ファイル(拡張子が png, jpg, jpeg, gif, webp, svg, avif, bmp, ico)だけである点と、選んだときに設定されるのが拡張子付きの絶対形式(`/images/my_image.png`)である点
- Crepe標準の画像機能(`CrepeFeature.ImageBlock`)は無効にしている。有効だと、画像が単独の段落にあるときにブロック画像として読み込まれ、保存時に代替テキストがサイズ倍率(`1.00` など)に置き換えられるため。無効にすると、画像は標準の image ノードになり、代替テキストとタイトルがそのまま保存される。副作用として、画像のドラッグによるリサイズと、画像下部のタイトル(キャプション)の表示・編集はできない。スラッシュメニューの標準の「Image」も消えるため、`MarkdownEditor.tsx` の `buildMenu` で自前の項目を足している
- 実装は `src/components/ImageDialog.tsx`(モーダル本体とドロップダウン。見た目は `LinkDialog.module.css` を共用している)と `MarkdownEditor.tsx`(メニュー項目と挿入)
