# リンクの設定

編集モードでは、リンク設定モーダルでリンクを挿入・変更する。

- テキストを選択すると出るツールバーのリンクボタン、またはMod+Kで、モーダルを開く(標準のリンクボタンの「付け外し」の動作は差し替えている)
- モーダルには「リンク先」と「リンクテキスト」の入力欄がある。初期値は次のとおり
  - カーソルがリンク上: 設定されているURLとリンクテキスト
  - テキスト選択中: どちらも選択中のテキスト(選択を優先する。選択がリンクの内側でも同じ)
  - それ以外: どちらも空欄
- 「リンクを挿入」を押す(Enterキーも同じ)と、カーソルがリンク上ならそのリンク全体、選択中なら選択範囲を、入力したリンクに置き換える。どちらでもなければカーソル位置に挿入する。リンクテキストが空欄のときは、リンク先をリンクテキストにする。置き換え前の先頭の文字の書式(太字など)は引き継ぐ
- リンク先が空欄(空白のみを含む)のときは「リンクを挿入」を押せない。Enterでも挿入されない
- 「キャンセル」、モーダルの外側のクリック、Escキーでモーダルを閉じる。閉じたあとはエディタにフォーカスが戻る
- モーダルでのリンクの解除はできない(次節のリンク解除で行う)
- リンク先の入力中は、文書にあるページやファイルを候補としてドロップダウンに表示し、選んでリンク先に設定できる(インクリメンタルサーチ)。仕様は次のとおり
  - 表示条件は、次のすべてを満たしたとき
    - リンク先を1文字以上入力している(日本語入力の変換中の未確定の文字列は無視し、確定済みの文字列で判断する)
    - リンク先の入力欄またはドロップダウンにフォーカスがある
    - 表示する候補が1つ以上ある
    - 入力されたリンク先に対応するページまたはファイルが実際に存在しない(存在すれば選択済みとみなす)。存在の判定は、現在のページのURLを基準にリンク先を解決してから、Server Action `linkTargetExists` でファイルの有無を調べる。`../` を含む入力も扱える。拡張子なしの `/dir/page` は `/dir/page.md` があれば存在とみなし、Markdown以外は拡張子付きのまま調べる
  - Escで閉じたあと、またはファイルを選んだあとは、次にリンク先を入力するまで表示しない
  - 候補は、ドットで始まるフォルダ・ファイル(`.oreno` を含む)を除く、文書ルート以下のすべてのファイル(Markdown以外も含む)。編集中のページ自身も含む
  - 候補は、次のA〜Cのいずれかに該当するファイル。大文字小文字は区別しない。複数に該当するときは最も優先度の高い条件だけに分類する。ファイル名は拡張子を含み、相対パスは文書ルートからの拡張子付きのパス
    - A: ファイル名が入力中のリンク先から始まる
    - B: 相対パスが入力中のリンク先から始まる
    - C: 相対パスが入力中のリンク先を含む
  - B・Cとの比較では、入力の先頭の `/` を1つ取り除く(リンク先は `/dir/page` の形で入力されることが多いため)
  - 並び順は、A、B、Cの順。同じ条件の中は相対パスの昇順(文字コード順)
  - 各行は、ファイル名の右に、フォルダのパス(文書ルートからの相対。末尾の `/` なし。ルート直下は `.`)を薄い色で並べる。幅に収まらない部分は見切れてよく、省略記号などは付けない
  - 設定されるリンク先は、文書ルートからの絶対形式(`/dir/page`)。Markdownは拡張子を省き、それ以外のファイルは拡張子付き(`/dir/image.png`)
  - ドロップダウンは、リンク先の入力欄の下に隙間なく付ける。高さは20件分までで、収まらないときはスクロールする
  - 下キーで、ドロップダウンにフォーカスが移り、先頭の候補が選択状態になる。上下キーで選択を切り替える。先頭で上キーを押すと入力欄にフォーカスが戻る。末尾で下キーを押しても何も起きない
  - 選択中にSpaceまたはEnterを押すと、そのファイルがリンク先に設定される。候補をクリックしたときは、選択状態にならず、すぐに設定される。どちらも、設定後にドロップダウンが消えて、入力欄にフォーカスが戻る
  - ドロップダウンにフォーカスがあるときのEscは、モーダルを閉じずにドロップダウンだけを閉じて、入力欄にフォーカスを戻す。ドロップダウンにフォーカスがある間は文字を入力できない。Tabキーの移動ではドロップダウンを飛ばす
  - ドロップダウンにフォーカスがあっても、リンク先の入力欄はフォーカスがあるときの見た目のままにする(CSSの `:focus-within` で実現している)。ドロップダウンの輪郭はフォーカスの有無で変えない
  - 候補のファイル一覧は、サーバーが保持している一覧を、モーダルを開いたときにServer Action `getCandidates` で取得する。同時にサーバーへ一覧の更新(スキャン)を依頼するが、完了は待たず、更新前の一覧をそのまま使う。更新が終わるまで1秒ごとに取り直し、終わったら新しい一覧に差し替える。最初のスキャンが終わっていないときは、候補の代わりに「(ファイル一覧を取得中...)」を表示する(選択できない)
  - 候補の絞り込みと並べ替えはクライアントで行う(`src/lib/candidates.ts`)
- ダークモード(OSの設定に従う)では、背景を暗くしたうえでモーダルを一段明るくして枠線を付け、範囲が分かるようにしている
- 実装は `src/components/LinkDialog.tsx`(モーダル本体とドロップダウン)、`linkEdit.ts`(対象範囲の判定と置き換え)、`MarkdownEditor.tsx`(ボタンの差し替えとMod+K)。Crepe標準のリンクツールチップ(リンク上に出る編集・削除の小窓)は、Crepeの `features` に `[CrepeFeature.LinkTooltip]: false` を指定して無効にしている

# ページ移動の入力欄

ヘッダー中央に、ページ名を入力してそのページへ移動する入力欄と、右に移動ボタン(矢印アイコン)がある。全画面共通のヘッダーに置いている。

- 入力すると、リンク設定モーダルのリンク先と同じ絞り込み・並び順(`searchCandidates`)で、ページやファイルの候補をドロップダウンに表示する。ファイル名の右にフォルダのパスを薄く出す点、20件分の高さでスクロールする点も同じ
- 候補のファイル一覧は、入力欄にフォーカスしたときに Server Action `getCandidates` で取得する(更新の依頼と1秒ごとの取り直しはリンク設定モーダルと同じ)。最初のスキャンが終わっていないときは「(ファイル一覧を取得中...)」を表示する
- 表示条件は、1文字以上入力している(日本語入力の変換中は確定済みの文字列で判断)、入力欄またはドロップダウンにフォーカスがある、候補が1つ以上ある、Escで閉じていない(次に入力するまで表示しない)。リンク設定モーダルと違い、入力に対応するファイルが存在しても閉じない
- 候補をクリックするか、下キーで選んでEnter/Spaceを押すと、そのページへ移動する。キーボードの操作(下キーでドロップダウンへ、上キーで入力欄へ戻る、Esc)はリンク設定モーダルと同じ
- 入力欄でEnter、または移動ボタンを押すと、候補を選択していればそれに、していなければ先頭の候補に移動する。候補がなければ何もしない。変換確定のEnterでは移動しない
- Markdownは拡張子を除いたURLへ画面遷移し、それ以外のファイルは通常のページ遷移でサーバーから直接開く
- 実装は `src/app/[...slug]/PageJumpBox.tsx`

# リンクの解除

編集モードでは、リンク設定モーダルとは別の操作でリンクを解除する(リンクのテキストは残り、リンクだけが外れる)。

- テキストを選択すると出るツールバーの、リンク設定ボタンの右隣にある「リンク解除」ボタンで、選択した部分のリンクを解除する。リンクの一部だけを選択したときは、その部分だけが解除され、残りはリンクのままになる。複数のリンクにまたがる選択は、選択範囲の中のリンクをすべて解除する
- 選択範囲にリンクがないときは、リンク解除ボタンは薄く表示して押せない状態にする
- 範囲選択なしでカーソルがリンク上にあるときは、リンクの真上にリンク解除ボタンだけを載せた小さなバーを表示する。押すとそのリンク全体を解除する。エディタからフォーカスが外れている間(リンク設定モーダルを開いている間など)は表示しない
- ショートカットは Mod+Alt+K。選択中なら選択した部分、カーソルがリンク上ならそのリンク全体を解除し、リンクがなければ何もしない。Mod+Shift+K にしていないのは、WindowsとLinuxのFirefoxで開発者ツールのコンソールに使われているため。MacのFirefoxではCmd+Option+Kがコンソールに使われているため、Firefoxでは使えないことがある
- ボタンのアイコンは、リンク設定ボタンの図形に右上から左下への斜線を重ねたもの(`src/components/unlinkIcon.ts`)
- 実装は `linkEdit.ts`(解除処理と、カーソルがあるリンクの範囲の判定)、`unlinkButtonPlugin.ts`(カーソルがリンク上にあるときのバー)、`MarkdownEditor.tsx`(ツールバーのボタンとショートカット)。ツールバーのボタンに「押せない状態」はないため、`active` を「解除できるリンクがある」の意味で使い、`active` でないときの見た目は `globals.css` で切り替えている
