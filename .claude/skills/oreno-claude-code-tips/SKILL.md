# 目的

このプロジェクト(oreno)のCLAUDE.mdや `.claude/skills/` の運用に活かせる、Claude Code関連の新しいノウハウを定期的に仕入れるためのスキルです。実行するたびにWebから最新情報を集めて紹介するところまでを行い、コードやSKILLファイルへの反映は行いません。紹介した内容のうちユーザーが気に入ったものがあれば、その場で改めて適用の指示を受けてから対応します。

# 収集対象

以下のサイトを中心に、Claude CodeのSKILL活用法・トークン使用量削減に関する記事を探します。目安として直近1年以内の新しめの記事を優先してください。これら以外にも有用な情報源(Zenn/Qiitaのトレンドページ、Anthropic公式ドキュメントの更新、個人ブログなど)があれば適宜追加して構いません。

- Qiita (https://qiita.com/) — 「Claude Code」「SKILL」「トークン削減」等のキーワードで検索
- はてなブックマーク ITカテゴリ人気エントリ (https://b.hatena.ne.jp/hotentry/it) — Claude Code関連のエントリを探す
- Zenn (https://zenn.dev/) — 同様にトピック検索

検索にはWebSearchツールを、個別記事の内容確認にはWebFetchツールを使ってください。

# 手順

1. 上記の情報源を中心にWeb検索し、Claude CodeのSKILL(スキル)の効果的な作り方・運用方法、およびトークン使用量削減に関するノウハウ記事を幅広く集める。
2. 集めた候補の中から、このプロジェクトの構成に実際に活かせそうなものを絞り込む。判断にあたっては以下を踏まえる。
   - README.md（プロジェクト概要）
   - CLAUDE.md（開発方針。特に「機能修正とリファクタリング」「質問への回答」の方針）
   - `.claude/skills/` 以下の既存SKILL(命名・分割の粒度・書き方)
   一般的すぎる基礎知識(SKILLとは何か、等の入門レベルの話)や、このプロジェクトの構成上そもそも関係ない内容は除外する。
3. 有効と判断したものを5件程度に絞り、それぞれ次の形式で日本語で紹介する。
   - タイトルと出典(サイト名・URL)
   - ノウハウの要点(2〜3行程度)
   - このプロジェクトにどう活かせそうか(具体的にどのSKILLや作業に効きそうか)
4. 紹介はここまでとし、SKILLファイルやコードの変更は行わない。ユーザーが気に入ったものがあれば、その場で適用方法を相談する。

# 紹介時の注意

- CLAUDE.mdの「質問への回答」方針に準じ、紹介は要点を簡潔にまとめる。聞かれていない周辺知識を長々と説明しない。
- 出典URLは必ず明記する。記事本文をWebFetchで確認してから紹介し、検索結果の見出しだけで又聞き的に紹介しない。
- プロジェクトに合う記事が少ない場合は無理に5件にこだわらず、件数を減らしてよい。逆に特に有効そうなものが多ければ増やしてもよい。
